# stanford.tel

Placeholder landing page for [stanford.tel](https://stanford.tel).

A single, self-contained `index.html` — no build step, no JavaScript, no external
requests. Dark/light aware, ~4 KB uncompressed.

## Deploy (GitHub Pages)

1. Push to the `main` branch.
2. In repo **Settings → Pages**, set the source to *GitHub Actions* (or *Deploy from a branch → main*).
3. The included `CNAME` file points the custom domain at `stanford.tel`. Add/confirm
   the domain in **Settings → Pages → Custom domain** and the DNS `A`/`AAAA` records.
